# ultron-local

Ultrón será una IA local para acompañarte en el día a día, conectada al hogar y a dispositivos como relojes o gafas inteligentes.

Responderá, aconsejará y tendrá personalidad propia: podrá llevarte la contraria cuando una decisión te ponga en peligro.

Comprenderá quién eres, tu ética y tu moral, para acompañarte de forma coherente con tus valores.

Estará conectada a internet para aprender con información objetiva y científica, priorizando siempre documentos verificables.

Todas las conversaciones se mantendrán en local, evitando compartir información con terceros.
