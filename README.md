# ultron-local
Ultrón será una IA local capaz de ayudar tanto en ambientes cotidianos como en profesionales. Responderá con voz y tendrá una personalidad propia, capaz de llevarte la contraria cuando la situación lo amerite (ej. quieres salir en manga corta un día lluvioso).Estará conectado a internet pero ninguna conversación saldrá del servidor local.
